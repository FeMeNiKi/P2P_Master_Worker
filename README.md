# P2P Master-Worker (scaffold)

Scaffold mínimo para o projeto P2P Master-Worker.

Instruções rápidas:

1. Crie e ative um virtualenv.

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

2. Rodar testes:

```powershell
pytest -q
```

3. Demo local (abre master e alguns workers):

```powershell
python scripts\run_demo.py
```
